# Student Attendance Management System

## Project Description
The Student Attendance Management System is a Java-based web application designed to manage student attendance efficiently.

## Technologies Used
- Java
- JSP and Servlets
- Maven
- HTML and CSS
- MySQL Database
- Apache Tomcat

## Features
- Student attendance management
- Attendance records
- Database connectivity
- Attendance tracking

## Project Structure
- `src/` – Java source code and web resources
- `database/` – Database files and SQL scripts
- `pom.xml` – Maven dependencies and configuration

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure the MySQL database.
4. Configure Apache Tomcat.
5. Run the application on the server.
